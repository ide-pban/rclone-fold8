rclone-fold8

rclone-fold8 is a personal OAuth client used by a single individual to run rclone on their own phone, in order to copy files from their own Google Drive to that phone. It is not offered to anyone else.

Privacy Policy

This application does not collect, store, sell, or share any user data. Files and access tokens move only between Google's servers and the owner's own device, through rclone running locally on that device. No data is sent to the developer or to any third party.

Google user data accessed through Google APIs is used only to synchronize the owner's own files, and its use complies with the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time from Google Account > Third-party apps.
